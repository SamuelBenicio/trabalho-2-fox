# Trabalho 2

Estrutura do trabalho de resolução de problemas em grafos.

## Diretórios

- `acompanhamento/`: registros dos marcos do trabalho.
- `src/`: código-fonte e módulos necessários.
- `evidencias/`: evidências de submissão ou execução.
- `apresentacao/`: arquivo da apresentação.
- `dados/`: casos de teste e outros dados de entrada.
